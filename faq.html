Frequently Asked Questions

What is GPU Render Studio?

GPU Render Studio is a fully automated GPU rendering platform for Blender. Projects are executed exactly as uploaded with no creative changes.

Which software is supported?

Blender with Cycles GPU on NVIDIA hardware is currently supported. Other engines may be introduced in later phases.

How does pricing work?

Each job uses a fixed execution slot that includes guaranteed base runtime. Overflow runtime is billed hourly after that window. CAP limits only overflow spending.

What is CAP?

CAP is a safety limit on extra cost beyond the slot price. It never affects execution during base runtime.

What happens when CAP is reached?

The job pauses automatically once overflow reaches the configured limit. Frames are preserved and no further billing occurs.

Do you run real GPU timing prechecks?

Yes. Test frames are rendered on physical NVIDIA GPUs before confirmation.

Can I track progress?

The live status page shows frame progress, ETA and billing counters.

When do I pay?

Payment is required before downloading completed results.

Where are your GPUs located?

All GPUs are hosted in the European Union. We serve customers worldwide and support GDPR-compliant workflows for privacy-sensitive projects.

What GPUs do you use?

All jobs currently run on NVIDIA RTX 5090 GPUs with dedicated access per node. As the platform scales, new capacity will be added at the same tier or higher.

What happens if rendering fails?

Failures are never billed. Partial jobs are charged only for completed runtime.

How long are files stored?

Data is retained temporarily and removed automatically.
