How Pricing Works

GPU Render Studio uses a slot-based model instead of unpredictable pay-as-you-go. Every job starts with a fixed-price runtime package. You may optionally allow hourly overflow and protect yourself with a CAP limit.

  1. Select a slot package.
  2. Optionally allow overflow.
  3. Set a CAP for extra spend.
  4. Follow progress in real time.

Slot Packages

Slot Base Runtime Price
STRICT1.5 hours$0.50
EXTENDED4 hours$2.00
FLEXIBLE8 hours$4.00
OPEN_FIXED_MAX12 hours$5.00

Slot time is always billed first and is guaranteed for the selected package.

Overflow Billing

If your render exceeds the slot window, overflow may continue at the hourly rate. Overflow is optional and must be explicitly enabled during contract confirmation.

  • No overflow unless you allow it.
  • Billed only after slot time is used.
  • Visible live in the status UI.

CAP Spending Limits

CAP defines how much extra you allow to spend after the slot price. It never replaces the base slot — it only limits overflow.

Example:
FLEXIBLE = 8h / $4
CAP = $4.50
→ Max total = $8.50
→ Runtime ≈ 12.5h
  • CAP applies only to overflow.
  • CAP never triggers inside slot window.
  • Jobs pause safely when CAP is reached.

Paused Jobs & Resume

When CAP is reached, rendering pauses automatically. Frames are preserved and billing is locked. You can later extend CAP and resume the job.
