How GPU Render Studio Works

GPU Render Studio is a fully automated Blender GPU rendering pipeline. Every job follows the same deterministic flow — from upload, to real GPU prechecks, to controlled billing and final delivery.

1. Upload Your Scene

Upload your Blender project through the web interface. Files are encrypted in transit and staged inside isolated execution environments.

  • Secure upload
  • Temporary storage
  • Automatic cleanup after retention period

2. Real GPU Precheck

Before committing to a full render, the system runs test frames on physical NVIDIA GPUs. This produces accurate runtime estimates and recommends the correct slot profile.

  • Frame sampling on real hardware
  • Cycles GPU execution
  • Performance-based slot recommendation

3. Slot Selection & Cost Controls

You select a fixed slot package that guarantees base runtime. Overflow may optionally continue at the hourly rate. A CAP lets you limit extra spend after the slot window ends.

  • Slot price always billed first
  • Overflow opt-in only
  • CAP limits overflow spend
  • No CAP enforcement during slot window

4. Automated Rendering

Jobs run unattended on NVIDIA GPUs inside sandboxed workers. Live telemetry is streamed to the status page.

  • Frame progress
  • ETA calculation
  • Billing counters
  • Pause states explained

5. Payment, Delivery & Resume

Payment is required only before final download. If CAP is reached, the job pauses safely and can later be resumed by extending the limit.

  • ZIP download bundles
  • No billing for technical failures
  • Resume supported
