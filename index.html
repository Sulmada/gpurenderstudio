Dynamic Capacity Windows

During low system load, some jobs may be allowed to run beyond their base runtime window at no additional cost.

These extensions are automatic, depend on real-time capacity, and are never guaranteed — but they can occasionally save you a re-submission.

Prices apply per completed job. Failed jobs are not charged. Each submission represents one execution attempt.
