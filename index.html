Execution Profiles & Pricing

Phase 1 uses fixed execution profiles. Each profile defines a base render window and a fixed price per job.

Price and base runtime are locked at submission. Pricing represents risk and capacity reservation — not guaranteed render time.

System Capacity

When system capacity is idle, the allowed render time may be extended beyond the base runtime of the selected profile.

This extension is automatic, does not affect price, cannot reduce the base runtime, and is not guaranteed.

Prices are per completed job. Failed jobs are not charged. One submission equals one execution attempt.
